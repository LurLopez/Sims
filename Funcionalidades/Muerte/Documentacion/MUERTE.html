Sistema de Muerte

Documentación técnica y de diseño del sistema de probabilidad de muerte por minuto en SIMS.

1. Descripción General

Cada minuto de juego el personaje tiene una pequeña probabilidad de morir. Esta probabilidad depende de dos factores:

  • Edad — factor dominante. El riesgo se dobla cada 10 años de vida (crecimiento exponencial).
  • Media de necesidades básicas — factor modulador. Buenas necesidades pueden reducir el riesgo hasta 35×. Malas necesidades prácticamente no dan protección.
La relación entre necesidades y esperanza de vida es casi perfectamente lineal:
esperanza_vida ≈ 50 + media_necesidades / 2

Con media=100 → 100 años · Con media=50 → 75 años · Con media=1 → 51 años

2. Fórmula

func Comprobar_Muerte() -> bool:
    # Límite duro: muerte garantizada al último minuto de la matriz (99 años)
    if Minute_Day >= 573 and Minute_Minute >= 1439:
        return true

    var edad = 18 + int(Minute_Day / 7.0)

    var media_nec = sum(Necesidades_Basicas) / 5.0      # 0–100

    var factor_edad = pow(2.0, (edad - 18) / 10.0)     # se dobla cada 10 años
    var factor_nec  = pow(35.0, media_nec / 100.0)     # rango [1.0, 35.0]

    # max_valor alto = más seguro; max_valor bajo = más peligroso
    var max_valor = max(1, int(1_875_000.0 * factor_nec / factor_edad))

    return randi() % max_valor == 0  # 1 en max_valor posibilidades de morir

3. Esperanza de vida por nivel de necesidades

La esperanza de vida es la edad a la que exactamente el 50% de las partidas ya han terminado (mediana estadística). La relación con las necesidades es casi perfectamente lineal.

8. Flujo de game over

  1. Actividades.Actualizar_Horario() llama Comprobar_Muerte() al final de cada tick de minuto.
  2. Si devuelve true: pone Muerto=true y Edad_Muerte, y Actualizar_Horario() retorna true inmediatamente (corta el loop).
  3. Script_Principal._process() detecta el retorno, llama Guardar_Variables_Dinamicas.save_game() y hace change_scene_to_file("res://Escenas/Menu/Menu.tscn").
  4. Si al cargar la escena principal Muerto==true (save de partida muerta): redirige al menú via call_deferred sin procesar ningún minuto.
  5. Menu._ready() detecta Muerto==true y llama _Mostrar_Game_Over().
  6. La pantalla muestra: edad de muerte, progreso final (Deporte / Académico / Manualidades), dinero, y carreras completadas o en progreso si las hay.
Pendiente: La pantalla de game over no tiene botón de "Nueva partida" todavía. Está previsto para una versión futura. De momento el jugador solo puede ver sus estadísticas.

9. Log de debug

Cada vez que se procesa un batch de minutos, el output de Godot imprime:

[Muerte] Edad: 71 | P.minuto: 0.00050175% (1 en 199301) | P.acumulada: 49.9409%
  • P.minuto: probabilidad de morir exactamente en ese minuto (1 / max_valor × 100).
  • P.acumulada: probabilidad de haber muerto en algún minuto anterior desde el inicio de la partida (1 − Prob_Supervivencia_Acumulada).
