🏠 Sistema de Alquiler Timer-Based

Versión: 1.0 | Fecha: 2026-05-27

📋 Descripción General

Sistema que permite al jugador elegir entre vivir en alquiler o en la calle, con un cobro automático cada 7 días reales (7 días de juego).

Objetivo: Dar libertad económica al jugador mientras mantiene presión financiera realista.

💰 Variables Principales

Variable Tipo Significado Rango
En_La_Calle bool true = sin alojamiento | false = alquilando true/false
Ultima_Fecha_Alquiler int Minuto absoluto del último alquiler pagado -1 (inactivo) o ≥0
Dinero int Dinero disponible (nunca negativo) ≥0

⚙️ Lógica de Cobro

Cada minuto de juego, se ejecuta esta verificación:

if not En_La_Calle and Ultima_Fecha_Alquiler >= 0: minutos_desde = Minute_Actual - Ultima_Fecha_Alquiler if minutos_desde >= 7 * 1440: # 7 días Cobrar_Alquiler()

📍 Flujo de Estados

Diagrama de transiciones:

ALQUILANDO (En_La_Calle=false) ↓ ├─→ [Usuario pulsa botón] → Confirmación → IR_A_LA_CALLE │ ↓ │ EN_LA_CALLE (En_La_Calle=true) │ ├─→ [Dinero ≥ 200€] → Pulsar botón → ALQUILANDO │ └─→ [Dinero < 200€] → Bloqueado (sin acción) │ └─→ [7 días sin pagar] ├─→ [Dinero ≥ 200€] → Paga 200€ → ALQUILANDO (timer reset) └─→ [Dinero < 200€] → Va automáticamente → EN_LA_CALLE

🔧 Funciones Implementadas

Cobrar_Alquiler()

Descripción

Intenta cobrar 200€. Si dinero < 200€, va automáticamente a la calle.

Lógica

if Dinero >= 200: Dinero -= 200 Ultima_Fecha_Alquiler = Minute_Actual else: Ir_A_La_Calle()

Ir_A_La_Calle()

Descripción

Marca al jugador como sin alojamiento. Se ejecuta automática o voluntariamente.

Efectos

  • En_La_Calle = true
  • Ultima_Fecha_Alquiler = -1 (anula timer)
  • Necesidades básicas caen a máximo 20

Volver_A_Alquiler()

Descripción

Intenta volver a alquiler. Requiere 200€ líquidos.

Lógica

if Dinero >= 200: En_La_Calle = false Dinero -= 200 Ultima_Fecha_Alquiler = Minute_Actual else: # No hace nada, se queda en la calle

📊 Casos de Uso

Caso 1: Nueva partida

Estado Inicial

  • Dinero: 1000€
  • En_La_Calle: false
  • Ultima_Fecha_Alquiler: minuto_actual

Qué ocurre

Después de 7 días reales, se cobra 200€.

Resultado: Dinero = 800€, Ultima_Fecha = minuto_del_cobro

Caso 2: Dinero insuficiente

Escenario

Tienes 150€ cuando llega la hora de pagar el alquiler.

Qué ocurre

✓ NO se cobran 200€

✓ Se conservan los 150€

✓ Automáticamente vas a la calle

✓ Necesidades caen a máximo 20

Caso 3: Volver del la calle

Escenario

Estás en la calle con 250€. Pulsas el botón "En la calle".

Qué ocurre

✓ Se cobran 200€ inmediatamente

✓ Te quedan 50€

✓ Vuelves a alquiler (En_La_Calle = false)

✓ Nuevo timer: próximo cobro en 7 días

Caso 4: Intenta volver sin dinero

Escenario

Estás en la calle con 150€. Pulsas el botón "En la calle".

Qué ocurre

Nada. Te quedas en la calle silenciosamente.

Tienes que conseguir 50€ más antes de poder volver.

🛡️ Protecciones Implementadas

Riesgo Protección
Dinero negativo Si no hay dinero, vas a la calle sin perder dinero
Explotar el fin de semana Volver a alquiler cuesta 200€ inmediatos (no hay gracia)
Irse por accidente Se pide confirmación al intentar ir a la calle
Desincronización de reloj Timer usa minutos absolutos, no depende del día semana

💾 Persistencia (Save/Load)

Al guardar:

Se persisten En_La_Calle y Ultima_Fecha_Alquiler

Al cargar:

Se recuperan ambas variables. Fallback para saves viejos: asume "en alquiler" con 7 días de gracia.

📈 Impacto en Necesidades Básicas

Cuando En_La_Calle = true O Dinero < 0:

  • Límite máximo de necesidades: 20
  • Las barras de salud caen rápidamente
  • Efecto psicológico: presión financiera

🐛 Notas Técnicas

  • Ejecución: Se verifica cada minuto en Actividades.Actualizar_Horario()
  • Timer absoluto: Usa Minute (minutos Unix), no depende del calendario gregoriano
  • Atomicidad: El cobro y la transición a calle son atómicos (no hay estado intermedio)
  • UI: Botón en parte superior izquierda (z_index=10, visible siempre)
