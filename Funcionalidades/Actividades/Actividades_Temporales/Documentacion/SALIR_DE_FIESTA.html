Salir de Fiesta — Euforia y Resacón

Actividad temporal P1 de alto riesgo y alta recompensa. Se programa entre las 18:00 y las 06:00, dura entre 2 y 12 horas y cada minuto calcula dos probabilidades independientes: ligar y resacón. El primer evento que sale se resuelve una sola vez por bloque.

2. Ventana horaria

Actividades.Validar_Horario_Fiesta(...) es una función pura:

{ "valido": true, "duracion_min": 720, "motivo": "" }
{ "valido": false, "duracion_min": 0, "motivo": "..." }
  • Inicio permitido: 18:00–04:00 inclusive.
  • Fin permitido: 20:00–06:00 inclusive. Las 24:00 se tratan como 00:00 del día siguiente.
  • 18:00–19:59 se rechaza por duración mínima (AC-04), no por el fin.
  • Cruce de medianoche: se deduce de las horas (inicio >= 18:00 y fin <= 06:00).
  • Duración mínima 120 min; máxima 720 min.
  • En un cruce se acepta el mismo día (se normaliza al siguiente) o el día siguiente, incluido domingo(6) → lunes(0).
  • Con semana informada, el día final absoluto no puede superar 573.
CasoMotivo
Inicio fuera de 18:00–04:00La fiesta debe empezar entre las 18:00 y las 04:00
Fin fuera de 20:00–06:00La fiesta debe terminar como máximo a las 06:00
Menos de 2 hLa fiesta debe durar al menos 2 horas

El selector trabaja con días 0–6. Para un cruce, SeleccionarHorarioReloj pasa a _Calcular_Rango el día dia_inicio + 1 (puede ser 7 = lunes siguiente). No se modificó _Calcular_Rango para el resto de actividades.

3. Fórmulas

3.1. Ligar

mod_edad = clamp(10.0 - (edad - 20) * 0.625, -25.0, 12.0)

puntaje_ligar = clamp(
    50
    + 0.30 * (NB[1] - 50)        # Salud Mental
    + 0.25 * (NB[4] - 50)        # Higiene
    + 0.20 * (Progreso[0] - 50)  # Deporte
    + 0.15 * (Progreso[1] - 50)  # Académico
    + 0.10 * (NB[3] - 50)        # Descanso
    + mod_personalidad
    + mod_edad,
    0, 100
)

prob_ligar_min = (0.00001 + 0.00099 * puntaje_ligar / 100) * mult_dia

Personalidad: Deportista +10, Culo_Del_Sofa −10, Trabajador_Compulsivo −5, resto 0.

Día de la nocheMultiplicador
Lunes–Miércoles (0–2)0.70
Jueves (3)1.00
Viernes (4)1.25
Sábado (5)1.45
Domingo (6)0.80

La noche pertenece al día en que empezó. El límite son las 06:00 inclusive: un domingo a las 06:00 todavía cuenta como noche del sábado.

3.2. Resacón

aguante_resacon = clamp(
    50
    + 0.40 * (NB[2] - 50)        # Hambre
    + 0.30 * (NB[3] - 50)        # Descanso
    + 0.20 * (NB[0] - 50)        # Salud Física
    + 0.10 * (Progreso[0] - 50)  # Deporte
    + mod_edad,
    0, 100
)

riesgo_resacon = (100 - aguante_resacon) / 100
prob_resacon_min = 0.00001 + 0.00099 * riesgo_resacon

El día de la semana y la personalidad no afectan al resacón.

3.3. Tirada por minuto

if randf() < prob_ligar_min:
    activar Euforia
elif randf() < prob_resacon_min:
    activar Resacon

Máximo un evento por bloque. Fiesta_Evento_Ocurrido se resetea en el primer minuto de un bloque nuevo; dos bloques adyacentes cuentan como uno solo.

4. Vista previa

Actividades.Simular_Preview_Fiesta(...) proyecta las necesidades minuto a minuto:

delta = signo(efecto) * min(1, abs(efecto) / frecuencia)
nb = clamp(nb + delta, 1, 100)

Frecuencias: física/mental 30, hambre 12, descanso 15, higiene 20.

p_ligar += supervivencia * pl
p_resacon += supervivencia * pr * (1 - pl)
supervivencia *= (1 - pl) * (1 - pr)
p_nada = supervivencia

Siempre se cumple p_ligar + p_resacon + p_nada = 1.

5. Flujo de creación

1. Actividades → Especiales → Salir de fiesta.
2. Se abre el selector en modo Fiesta con el panel de preview y una franja propuesta dentro de 18:00–06:00 (o la marcada antes en el calendario).
3. Ajustar inicio y final → Crear actividad: valida con Validar_Horario_Fiesta y escribe en la matriz.

Si se parte del calendario, Elegir actividad conserva la franja marcada y abre el catálogo; al elegir la actividad se vuelve al selector para confirmar el horario. El resto de actividades sigue el mismo orden: primero la actividad y después el horario.

6. Estados temporales

Euforia

  • Duración: 1440 min.
  • Primeras 8 h (480 min): suelo de Salud Mental = 100.
  • Últimas 16 h (960 min): baja linealmente de 100 a 50.
  • Al activarse: Salud Mental sube a 100 (o 20 en calle/bancarrota).
  • Sustituye a Resacon.

Resacón

  • Duración: 1440 min.
  • Primeras 8 h: techo de Salud Física y Mental = 30.
  • Últimas 16 h: sube linealmente de 30 a 100.
  • Al activarse: Salud Física y Mental se recortan a 30 (o 20 en calle/bancarrota).
  • Sustituye a Euforia.
  • Mientras está activo, ninguna actividad puede subir física o mental por encima del techo.

La fórmula de Euforia usa floor(100 - progreso * 50) para que 720 → 87 y 240 → 62 coincidan con la tabla aprobada.

Tick

  1. Se aplica el efecto con el contador actual.
  2. Se descuenta 1 minuto.
  3. Si llega a 0, se elimina y se añade el mensaje de fin.

Tick_Estados() se ejecuta siempre, esté o no el personaje de fiesta.

8. Persistencia

var Estados_Temporales: Dictionary = {}   # { "Euforia": minutos } o { "Resacon": minutos }
var Fiesta_Evento_Ocurrido: bool = false
  • Save antiguo sin campos → {} y false.
  • Valores convertidos a int y limitados a 0..1440.
  • Claves desconocidas filtradas.
  • Si un save corrupto trae ambos estados, se conserva el que tenga más minutos restantes (empate → Resacon).
  • Menu._reiniciar_partida_desde_cero() resetea ambos campos.
